Style proposals — 91mm SAK Builder

Four visual directions for a more elaborate, realistic rendering of the knife and a more modern layout. Each proposal is a standalone static mockup of the same screen (tool palette · front/back preview of a Climber stack · layers / matches / shopping list). Open a file directly in a browser — no server needed.

1Atelier

Product-render realism: gradient Cellidor scales, brushed-steel layers, rivets, glossy emblem, soft drop shadows. Warm paper background, rounded cards, large numerals.

Best for: a premium “gear shop” feel; makes the knife preview look like a real product photo.

2Blueprint

Dark engineering-sheet look: grid background, hatched layers, dashed centerlines, dimension arrows (91.0 mm / 17.2 mm), title block, monospace data.

Best for: a technical/spec-sheet feel that highlights layer order and real measurements.

3Swiss editorial

International typographic style — fitting for Victorinox: pure white, hairline black rules, one red accent, sharp unrounded chips, big grotesque numerals, strict 3-column grid.

Best for: a clean, editorial, “Swiss design” identity; fastest and most readable.

4Tactical

Rugged outdoor look: dark knurled scales, hard offset shadows, amber accents, condensed uppercase type, bordered chips, lanyard hole.

Best for: an outdoorsy / EDC-community vibe that stands out from typical “clean SaaS” UIs.

53D orbit (pure CSS 3D, no library)

Interactive 3D knife built from CSS-3D cuboids: red scales with rivets + emblem, steel layers with tool chips. Drag to orbit, wheel to zoom, “explode” slider to separate layers. Blueprint / Tactical UI toggle.

Best for: showing the real object and the layer stack in 3D — answers “can we render the knife in 3D?” without WebGL or any dependency.

63D tool models (canvas software 3D, zero deps)

Each tool is a real 3D model (extruded photo-informed profile or helix tube — silhouettes based on SAKwiki’s 91mm tool gallery) hinged on the knife body. Click a tool in the palette: it folds open in 3D. Orbit/zoom + OPEN slider. Blueprint/Tactical toggle.

Best for: showing which tool does what — 12 tools modeled (blades, corkscrew, scissors, pliers, openers, awl, hook, saws, magnifier).
Static mockups for review — once a direction is chosen, it gets ported into build_webapp.py (the generator of sak_builder.html).
